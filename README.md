# 🎮 **GameStart — Mobile Gaming Store App**  
*A React Native + Expo Project for COMP 490*

Welcome to **GameStart**, a modern mobile shopping experience for gamers.  
Browse video games, consoles, and accessories — add items to your cart — and enjoy smooth UI animations powered by Expo + TypeScript.

---

## 🌟 **What This App Does**
> A clean mobile store interface built for learning, design, and functionality.

✔ Browse **Games**, **Consoles**, **Accessories**  
✔ Live Game Data via **RAWG API**  
✔ **Search** + category filtering  
✔ Full **Shopping Cart System** (Add, Remove, Update Quantity)  
✔ **Dynamic Cart Badge** on tab bar  
✔ Clean UI / UX design for mobile  
✔ Simple **Sign-In** and **Profile** demo screens
